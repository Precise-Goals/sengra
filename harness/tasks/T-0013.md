# T-0013 — Security Bonus Layer: CVE Blast Radius & Cross-Domain Fraud Bridge

Backlog ref: `BL-014` · Sprint: `Sprint 5` · Priority: `Could`

## Intent
Implement the Security Bonus Layer connecting infrastructure and software vulnerability graphs with financial fraud graphs. Implement Zod security schemas in `@sengra/schema`, security MCP tools in `@sengra/tools` (`cve_to_fraud_links`, `blast_radius`, `evaluate_finding_priority`, `who_knows_system`), and build the interactive Security Operations Console at `apps/web/src/app/security/page.jsx`.

## Scope / Out of scope
- **In Scope**:
  - `packages/schema/src/security.js`: Zod schemas for `Service`, `Package`, `CVE`, `Credential`, `Datastore`, `Exposure`, `Team`, `Engineer`.
  - `packages/tools/src/security.js`: Implementation of `cve_to_fraud_links`, `blast_radius`, `evaluate_finding_priority`, and `who_knows_system`.
  - `packages/tools/src/index.js`: Registering security tools in catalog and executor.
  - `apps/web/src/app/security/page.jsx`: Interactive Security Ops Console showing CVE blast radius, cross-domain bridge query, and triage escalation.
  - `tests/unit/test-security.test.js`: Comprehensive unit tests.
- **Out of Scope**:
  - Multi-agent split (deferred to stretch).

## Requirements
- `REQ-013`: Cross-domain bridge query connecting CVE vulnerability to account takeover fraud.
- `REQ-004`: Security tools discoverable and executable via MCP tool catalog.

## Acceptance
- `AC-014-a`: Security Zod schemas validate `Service`, `CVE`, `Credential`, `FindingPriority`, and `BlastRadius`.
- `AC-014-b`: `cve_to_fraud_links` identifies compromised accounts linked to vulnerable auth service and CVE.
- `AC-014-c`: `evaluate_finding_priority` elevates fraud-linked vulnerabilities to P0 CRITICAL with priority score $> 85$.
- `AC-014-d`: Next.js `/security` console renders interactive cross-domain bridge visualizer and passes build.
