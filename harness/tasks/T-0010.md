# T-0010 — Animated Graph Evidence Path Synchronization

Backlog ref: `BL-011` · Sprint: `Sprint 3` · Priority: `Must`

## Intent
Implement animated graph traversal path synchronization in `@sengra/ui` (`animateEvidencePath`) and connect it to the dark ops console in `apps/web/src/app/page.jsx`. Clicking an alert or "Animate Path" steps through the evidence path in sync with the agent's reasoning explanation, completing Sprint 3.

## Scope / Out of scope
- **In Scope**:
  - `packages/ui/src/path-animator.js`: Sequencer animating Cytoscape nodes and edges hop-by-hop with step callbacks.
  - `packages/ui/src/index.js`: Exporting animation utilities.
  - `apps/web/src/app/page.jsx`: Adding animated playback controls and synchronized explanation subtitle banner.
  - Unit tests verifying animation sequence timing, step callback dispatch, and edge resolution.
- **Out of Scope**:
  - Baseline comparison tables (handled in Sprint 4).

## Requirements
- `REQ-006`: Visual explainability with synced animated evidence paths.
- `REQ-007`: Interactive dark ops console.

## Acceptance
- `AC-011-a`: `createPathAnimationSequence(pathNodeIds)` generates valid ordered step transitions.
- `AC-011-b`: Step progression dispatches `onStep(nodeId, index, total)` callback.
- `AC-011-c`: Dark ops console provides one-click path animation playback with synchronized sentence display.
