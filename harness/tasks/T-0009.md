# T-0009 — Live Trace Panel & Case Report Card

Backlog ref: `BL-010` · Sprint: `Sprint 3` · Priority: `Must`

## Intent
Implement dedicated, modular UI components in `@sengra/ui` for real-time investigation trace streaming (`TracePanel`), structured case verdict cards (`CaseCard`), and topological metrics bar (`MetricsBar`), integrated into the dark ops console in `apps/web/src/app/page.jsx`.

## Scope / Out of scope
- **In Scope**:
  - `packages/ui/src/case-card.jsx`: Case card component rendering verdict, confidence score, evidence path, and Skeptic badge.
  - `packages/ui/src/trace-panel.jsx`: Multi-step reasoning trace with collapsible tool inputs and outputs.
  - `packages/ui/src/metrics-bar.jsx`: Topological metrics summary bar (graph density, community count, bridge nodes).
  - Integration into `apps/web/src/app/page.jsx`.
  - Unit tests verifying component props, badge rendering, and verdict mapping.
- **Out of Scope**:
  - Animated path stepping timer (handled in T-0010).

## Requirements
- `REQ-006`: Visual explainability with evidence path citations.
- `REQ-007`: Real-time streaming trace and case card.

## Acceptance
- `AC-010-a`: `CaseCard` renders decision badge with correct styling (`FREEZE` = red, `NO_ACTION` = emerald, `HOLD` = amber) and formatted confidence.
- `AC-010-b`: `TracePanel` renders tool steps with timestamps and collapsible details.
- `AC-010-c`: `MetricsBar` displays density, community count, and bridge node count.
- `AC-010-d`: Unit test suite in `tests/unit/test-case-card.test.js` passes 100%.
