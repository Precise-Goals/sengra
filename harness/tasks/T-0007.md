# T-0007 — Cross-Session Memory & Audit Persistence

Backlog ref: `BL-008` · Sprint: `Sprint 2` · Priority: `Must`

## Intent
Implement cross-session memory in `@sengra/memory` storing past investigation cases, audit trails, and clearance decisions in FalkorDB graphs `agent_memory` and `decisions`. Enable the agent in session 2 to recall and cite findings from session 1, satisfying the Sprint 2 exit gate.

## Scope / Out of scope
- **In Scope**:
  - `packages/memory/src/cases.js`: Case creation, lookup, and updates.
  - `packages/memory/src/decisions.js`: Decision audit logging and evidence path tracking.
  - `packages/memory/src/recall.js`: Cross-session recall engine searching past investigations by entity ID.
  - `packages/memory/src/index.js`: Main memory module exports.
  - Unit tests verifying case creation, decision persistence, and cross-session recall linking session 1 to session 2.
- **Out of Scope**:
  - Frontend Cytoscape trace rendering (handled in Sprint 3).

## Requirements
- `REQ-004`: Persistent memory across sessions in FalkorDB `agent_memory` and `decisions`.
- `REQ-005`: Policy decisions and evidence path audit trail.
- `REQ-008`: Skeptic clearance records persisted for future session reference.

## Acceptance
- `AC-008-a`: `saveCase()` persists investigation case record with case ID, target entity, and timestamp.
- `AC-008-b`: `saveDecision()` logs structured decision, evidence path, confidence, and policy version.
- `AC-008-c`: `findPastInvestigations(entityId)` retrieves historical cases and verdicts for an entity.
- `AC-008-d`: A second session investigating an entity successfully recalls and cites prior clearance or freeze decision from session 1.
