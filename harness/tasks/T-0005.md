# T-0005 — MCP Tool Catalog & Handler Implementation

Backlog ref: `BL-006` · Sprint: `Sprint 2` · Priority: `Must`

## Intent
Implement the MCP tool catalog and execution engine in `@sengra/tools`, providing the agent with standardized tools for graph recall, Graphology analytics, policy evaluation, skeptic verification, simulated account actions, and audit logging. Provide the JSON-RPC 2.0 MCP route handler at `apps/web/src/app/api/mcp/route.js`.

## Scope / Out of scope
- **In Scope**:
  - `packages/tools/src/catalog.js`: Tool definitions with schemas and descriptions.
  - `packages/tools/src/handlers/*.js`: Tool execution handlers invoking `@sengra/graph`, `@sengra/analysis`, `@sengra/policy`, and memory mocks.
  - `packages/tools/src/index.js`: Main tool registry and executor `executeTool(name, params)`.
  - `apps/web/src/app/api/mcp/route.js`: Next.js App Router POST handler supporting JSON-RPC 2.0 `tools/list` and `tools/call`.
  - Unit tests verifying tool schemas, validation, execution, and injection safeguards.
- **Out of Scope**:
  - Streaming LLM agent loop (handled in T-0006).
  - Cytoscape visualization components (handled in Sprint 3).

## Requirements
- `REQ-002`: MCP tool catalog compliant with Model Context Protocol specification.
- `REQ-003`: In-process Graphology analysis tool invocation.
- `REQ-005`: Gated policy execution for freeze actions.
- `REQ-008`: Skeptic challenge tool invocation.
- `REQ-009`: Read-only Cypher fallback with query safety checks.

## Acceptance
- `AC-006-a`: `tools/list` returns all 11 core fraud tools with valid JSON Schema parameter signatures.
- `AC-006-b`: `executeTool("evaluate_freeze_policy", params)` and `executeTool("analyze_subgraph", params)` return deterministic results matching `@sengra/policy` and `@sengra/analysis`.
- `AC-006-c`: `executeTool("run_cypher_readonly", params)` rejects mutations (`DELETE`, `CREATE`, `SET`, `MERGE`, `DROP`) and limits rows to 1,000.
- `AC-006-d`: `/api/mcp` handles POST requests for `tools/list` and `tools/call` with valid JSON-RPC 2.0 responses.
