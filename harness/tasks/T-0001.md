# T-0001 — CI Workflow & Environment Configuration

Backlog ref: `BL-000` · Sprint: `Sprint 0` · Priority: `Must`

## Intent
Configure GitHub Actions CI workflow to run Quality Gate G0 on push/pull request, provide comprehensive `.env.example` template with FalkorDB Cloud and Anthropic configurations, and verify Sprint 0 exit gates.

## Scope / Out of scope
- **In Scope**:
  - GitHub Actions CI workflow in `.github/workflows/harness.yml` executing `check_harness.py` and `pytest tests/harness`.
  - `.env.example` documenting all required environment variables (`FALKORDB_HOST`, `FALKORDB_PORT`, `FALKORDB_USERNAME`, `FALKORDB_PASSWORD`, `FALKORDB_TLS`, `FALKORDB_GRAPH_PREFIX`, `ANTHROPIC_API_KEY`, `MCP_SHARED_SECRET`).
  - Sprint 0 exit gate evaluation.
- **Out of Scope**:
  - Production deployment workflows.

## Requirements
- `REQ-000`: Automated harness integrity verification in CI.

## Acceptance
- `AC-001-env`: `.env.example` documents all connection and authentication parameters.
- `AC-001-ci`: `.github/workflows/harness.yml` validates G0 on push.
- `AC-001-gate`: G0 passes cleanly on local execution.
