# T-0008 — Dark Ops Console & Cytoscape Canvas

Backlog ref: `BL-009` · Sprint: `Sprint 3` · Priority: `Must`

## Intent
Implement the dark ops financial crime investigation console layout in `apps/web/src/app/page.jsx` and the Cytoscape graph canvas component in `@sengra/ui` (`GraphCanvas`, graph stylesheet, node type badges, and interaction handlers).

## Scope / Out of scope
- **In Scope**:
  - `packages/ui/src/styles.js`: Cytoscape stylesheet definitions with entity color coding (Account: cyan/blue, Device: violet, Bad Device: bright red, Address: amber, Card: emerald).
  - `packages/ui/src/graph-canvas.jsx`: React Cytoscape graph canvas component.
  - `packages/ui/src/index.js`: UI package exports.
  - `apps/web/src/app/page.jsx`: Dark ops cockpit layout with header stats, alert trigger buttons (Ring A, Ring B, Ring C), graph canvas viewport, and inspector dock.
  - Unit tests verifying style mapping, node color logic, and component exports.
- **Out of Scope**:
  - Step-by-step path animation syncing (handled in T-0010).

## Requirements
- `REQ-006`: Cytoscape.js interactive graph visualization with custom styling and layouts.
- `REQ-007`: Dark mode cybersecurity / fintech ops console.

## Acceptance
- `AC-009-a`: `cytoscapeStyles` maps node types to distinct visual cues (known_bad devices highlighted in bold red `#ef4444`).
- `AC-009-b`: `GraphCanvas` renders graph elements without throwing exceptions.
