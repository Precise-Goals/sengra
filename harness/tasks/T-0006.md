# T-0006 — Agent Loop with Vercel AI SDK & Streaming Chat Route

Backlog ref: `BL-007` · Sprint: `Sprint 2` · Priority: `Must`

## Intent
Implement the streaming fraud investigation agent loop in `@sengra/agent` using Vercel AI SDK (`ai`), system prompt engineering for graph traversal and skeptic challenges, AI SDK tool adapters, and streaming App Router handler at `apps/web/src/app/api/chat/route.js`.

## Scope / Out of scope
- **In Scope**:
  - `packages/agent/src/prompt.js`: System prompt defining the Fraud Investigator persona, Rule F4 guidelines, and Skeptic challenge protocol.
  - `packages/agent/src/tools.js`: AI SDK tool definitions mapping `@sengra/tools` into `tool()` wrappers with Zod validation.
  - `packages/agent/src/orchestrator.js`: Investigation workflow runner and offline deterministic simulator.
  - `packages/agent/src/index.js`: Main exports (`SYSTEM_PROMPT`, `createAgentTools`, `runInvestigation`).
  - `apps/web/src/app/api/chat/route.js`: Next.js App Router streaming chat endpoint.
  - Unit tests verifying prompt assembly, tool conversion, and multi-step investigation loop.
- **Out of Scope**:
  - Full-page Cytoscape rendering (handled in Sprint 3).
  - Cross-session memory persistence (handled in T-0007).

## Requirements
- `REQ-001`: Multi-step reasoning agent with autonomous graph traversal.
- `REQ-002`: Tool-calling integration via Vercel AI SDK.
- `REQ-005`: Policy-gated decision output.
- `REQ-008`: Skeptic challenge execution before action.

## Acceptance
- `AC-007-a`: `SYSTEM_PROMPT` enforces graph analysis, skeptic challenge rules, and Rule F4 criteria.
- `AC-007-b`: `createAgentTools()` converts `@sengra/tools` into AI SDK compliant tool definitions.
- `AC-007-c`: `runInvestigation()` autonomously runs multi-step investigation on suspect account (recalls entity, runs Louvain/betweenness analysis, tests skeptic challenge, evaluates policy).
- `AC-007-d`: `/api/chat` handles POST requests with messages and streams or returns structured investigation trace.
