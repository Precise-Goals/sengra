# T-0012 — Evaluation Suite & Side-by-Side Compare View

Backlog ref: `BL-013` · Sprint: `Sprint 4` · Priority: `Must`

## Intent
Implement the quantitative evaluation benchmark suite in `packages/eval/src/evaluator.js` (accessible via `pnpm eval`), computing precision, recall, F1, and false-positive rates against ground truth. Build the interactive side-by-side `/compare` view at `apps/web/src/app/compare/page.jsx` to visually contrast graph intelligence against flat-table heuristics, completing Sprint 4.

## Scope / Out of scope
- **In Scope**:

  - `packages/eval/src/cli.js`: Standalone CLI runner invoked by `pnpm eval`.
  - `packages/eval/src/index.js`: Exporting batch evaluation functions.
  - `apps/web/src/app/compare/page.jsx`: Next.js `/compare` interactive side-by-side comparison page.
  - Unit tests in `tests/unit/test-evaluator.test.js`.
- **Out of Scope**:
  - Security CVE blast radius queries (handled in Sprint 5).
