# T-0003 — Seeded Synthetic Data Generator & Ground Truth

Backlog ref: `BL-002` · Sprint: `Sprint 1` · Priority: `Must`

## Intent
Implement deterministic synthetic graph generation in `@sengra/data` planting Ring A (8 mule ring accounts, 2 shared devices with D-17 known bad, circular payments, 1 collector), Ring B (5 family cluster accounts sharing IP and address without bad devices), Ring C (account takeover chain), noise, and generate `packages/data/ground_truth.json` for evaluation.

## Scope / Out of scope
- **In Scope**:
  - `packages/data/src/generator.js`: Deterministic seeded data generator using `@faker-js/faker` producing 1,500–3,000 nodes.
  - `packages/data/src/ground-truth.js`: Defines planted ring memberships, true positives, and false-positive test groups.
  - `packages/data/src/seed.js`: CLI seeding runner (`pnpm seed`, `pnpm seed:reset`) loading into FalkorDB `domain` graph.
  - `packages/data/ground_truth.json`: Exported ground truth file.
  - Unit tests verifying generator reproducibility, node counts, and planted ring structures.
- **Out of Scope**:
  - Live FalkorDB production network mutations.

## Requirements
- `REQ-009`: Deterministic synthetic dataset generator with planted scenarios.

## Acceptance
- `AC-009-a`: Generator deterministically outputs ~1,500–3,000 nodes with identical IDs and edges given the same seed.
- `AC-009-ring-a`: Ring A contains 8 accounts, 2 shared devices (including known bad D-17), and circular payment flows.
- `AC-009-ring-b`: Ring B contains 5 accounts sharing an address and IP with zero known bad devices.
- `AC-009-gt`: `ground_truth.json` correctly tags Ring A, Ring B, and Noise accounts.
